# Quickstart & Validation: Modern UI Restyle (Pico CSS)

**Feature**: 002-modern-ui-styling | **Date**: 2026-08-20

This guide validates the restyle end-to-end. It does not contain implementation code — see
[plan.md](./plan.md), [research.md](./research.md), and [contracts/ui-contract.md](./contracts/ui-contract.md)
for design detail, and `tasks.md` (generated by `/speckit-tasks`) for the build steps.

## Prerequisites

- Python 3.12 virtual environment with project dependencies installed.
- Node.js is **not** required (Pico is a vendored static asset; no build step).
- Vendored `static/css/vendor/pico.min.css` present at a pinned version (record the exact version
  in the file header).

## Setup

```bash
python manage.py migrate
python manage.py seed_site          # idempotent; creates the page tree used by the audited URLs
python manage.py runserver          # site at /, admin at /cms/
```

## Manual validation scenarios

Map each to the UI contract (Cn) and spec requirement.

1. **Cohesive look (US1 / SC-001, SC-002)** — Visit `/`, `/about/`, `/projects/`,
   `/projects/sample-project/`, `/blog/`, `/blog/sample-article/`, `/contact/`. Confirm shared
   typography, spacing, nav, and footer; confirm no page looks unstyled or legacy. Confirm each
   StreamField block (heading, paragraph, code, image, quote) renders cleanly (C3).

2. **Dark / light theme (US2 / SC-003)** — Set OS/browser to **dark**, reload each page: coherent
   dark theme, legible text. Switch to **light**, reload: light theme. Verify controls and error
   states are legible in both (C1, C6).

3. **Responsive / no overflow (US3 / SC-005)** — In devtools, set viewport width to **360px**. Load
   each page; confirm no horizontal page scroll; wide code blocks/tables/images scroll within their
   container (C7).

4. **Keyboard & skip link (US3 / FR-008)** — From page top, press Tab: the **Skip to content** link
   appears and is focusable; continue tabbing through nav, links, and form fields — focus is always
   visible and order is logical (C1, C5, C8).

5. **Contact form, no-JS (US3 / SC-006)** — Disable JavaScript. Submit `/contact/` empty → styled
   error summary + per-field errors. Submit valid data → styled landing/success. Confirm the honeypot
   field stays hidden and spam protection still applies (C6).

## Automated validation

```bash
# Format, lint, type-check (Python unchanged, must stay clean)
ruff format . && ruff check . && mypy .

# Unit tests (isolated)
pytest -m "not integration"

# Integration flows + combined coverage gate (>= 80%)
pytest -m integration --cov-append --cov-fail-under=80

# Rendering assertions for this feature (Pico linked, skip-link preserved, blocks render)
pytest core/tests/test_rendering.py --no-cov
```

Expected: all suites pass; combined coverage stays ≥ 80% (Constitution II). Existing performance
tests (query counts) remain unaffected.

## Accessibility gate (acceptance)

```bash
# Serve the site, then run the WCAG2AA/axe audit over the configured URLs
npx pa11y-ci        # uses .pa11yci.json
```

Expected: **zero new violations** vs. the pre-restyle baseline on all URLs (SC-004, FR-010, C8).

## Performance check (budget)

- Compare FCP and total page weight for a representative page (e.g., `/blog/sample-article/`) before
  and after the restyle (browser devtools / Lighthouse). Expected regression **≤ 10%** (SC-007, C9).
- Confirm no render-blocking third-party requests were added (CSS is served from `/static/`).

## Done when

- All manual scenarios pass in both light and dark themes.
- All automated suites pass; coverage ≥ 80%; `pa11y-ci` clean.
- Performance within the ≤10% budget; no external CSS request introduced.
